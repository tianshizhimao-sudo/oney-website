# CBA 更新 Trust 贷款 Trustee 资格要求

> **Detected**: 04/06/2026, 6:17:00 am
> **Source**: [[Commonwealth Bank]]
> **Significance**: 🔴 HIGH

## 📋 概述

CBA 宣布更新 Trust 贷款的 Trustee 资格要求，新增个人 Trustee 必须是 Beneficiary 的条款

## 🔄 变化详情

### What Changed
Trustee 资格要求增加新条件

### Before
```
允许任何个人或公司作为 Trustee
```

### After
```
个人 Trustee 必须同时是 Trust 的 Beneficiary；公司 Trustee 的 Director 必须是 Beneficiary
```

## 📊 影响分析

### Impact Level
- **Significance**: high
- **Affected Users**: [[investor]]

### Key Implications
影响使用个人 Trustee 的投资者，可能需要修改 Trust 结构或更换 Trustee
