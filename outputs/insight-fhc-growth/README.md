This directory contains all content generated by the `insight_to_fhc_growth_v1` routine.

Each execution creates a dated folder:

```

├── main-article.md          # Enhanced article with FHC CTAs
├── xhs-version.md           # 小红书 short-form version
├── linkedin-version.md      # LinkedIn professional version
```

## 📋 File Descriptions

### `main-article.md`
- **Purpose**: Primary long-form article for Oney website
- **Features**:
  - Comprehensive topic coverage
  - Natural FHC CTA integration (mid-article + end)
  - Examples and calculations
  - Clear call-to-action buttons
- **Target**: Website visitors, SEO traffic
- **Publish to**: `/insights/[topic-slug].html`

### `xhs-version.md`
- **Purpose**: Adapted for 小红书 (Little Red Book) audience
- **Features**:
  - Strong hook at top
  - Bullet points and emojis
  - Shorter, scannable format
  - Result-oriented language
  - Simplified CTA
- **Target**: Chinese-speaking millennials, visual learners
- **Publish to**: 小红书 platform

### `linkedin-version.md`
- **Purpose**: Professional network sharing
- **Features**:
  - Industry analysis angle
  - Data and trends focus
  - Professional tone
  - Softer, relationship-building CTA
- **Target**: Brokers, advisors, professionals
- **Publish to**: LinkedIn (company page or personal)

### `seo-metadata.json`
- **Purpose**: SEO configuration
- **Contains**:
  - Title tag
  - Meta description
  - Keywords
  - Open Graph tags (social sharing)
  - Twitter Card tags
  - Structured data (Schema.org)
  - Internal/external links
  - Target search queries
- **Use**: Copy into HTML `<head>` section

### `analysis.json`
- **Purpose**: Strategic documentation
- **Contains**:
  - Target user analysis
  - Pain point identification
  - Conversion strategy rationale
  - Funnel design
  - Success metrics
  - A/B test suggestions
  - Confidence assessment
- **Use**: Team review, performance tracking

## 📊 Performance Tracking

### Required UTM Parameters

All FHC links should include:
```
?source=insight
&medium=article
&campaign=[topic-slug]
&content=[cta-position: mid-article|end-article]
```

Example:
```
https://oney.co/fhc?source=insight&medium=article&campaign=fhg2026&content=mid-article
```

### Metrics Dashboard

Track these KPIs per article:
- **Pageviews**: Total article traffic
- **CTR**: % clicking FHC CTA
- **FHC Starts**: # entering FHC tool
- **FHC Completions**: % completing FHC
- **Broker Bookings**: % booking consultation

## 🚨 Common Issues & Solutions

### Issue: CTA feels too pushy
**Solution**: Add more educational content before CTA, soften language from "Buy now" to "See if this could help you"

### Issue: Low CTR
**Diagnose**:
- Is pain point clearly established?
- Is FHC positioned as solution to that specific pain?
- Is CTA visible and clear?
- Is timing right (too early/late in article)?

### Issue: High CTR but low FHC completion
**Diagnose**:
- Are expectations set correctly in CTA?
- Is FHC too long/complex?
- Is there a disconnect between article promise and FHC delivery?
