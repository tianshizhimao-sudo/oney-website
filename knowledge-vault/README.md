# Oney Knowledge Vault

This is an Obsidian vault for tracking Australian home loan policies, market changes, and insights.

## 📁 Structure

```
knowledge-vault/
├── 知识库/
│   ├── 政策追踪/          # Policy change tracking
│   ├── 银行信息/          # Bank-specific information
│   ├── 分析笔记/          # Analysis notes
│   ├── Trust专题/         # Trust Home Loan focus
│   └── 时间线/            # Timeline of changes
├── templates/            # Note templates
└── .obsidian/           # Obsidian configuration
```

## 🎯 Purpose

This vault is automatically populated by the **Policy Radar Monitor v1** system, which:

1. **Monitors** bank policy changes (especially Trust Home Loan policies)
2. **Detects** significant changes in real-time
3. **Creates** structured Obsidian notes for each policy change
4. **Links** related policies and topics automatically
5. **Triggers** downstream content generation (Insight Generator)

## 🏷️ Tags

- `#policy` - Policy changes
- `#trust` - Trust-related policies
- `#bank` - Bank-specific information
- `#rba` - RBA announcements
- `#rate` - Interest rate changes
- `#lvr` - LVR policy changes
- `#change` - Any change event

## 📊 Key Topics

### Trust Home Loan (Priority)

Trust lending policies are critical for:
- Investors using trust structures
- High net worth clients
- Asset protection strategies
- Tax planning considerations

Common policy changes to track:
- Trustee eligibility requirements
- Beneficiary income assessment
- Trust deed documentation requirements
- LVR limits for trusts vs personal names
- Trust lending rate premiums

### Other Monitored Topics

- Interest rates (RBA cash rate, variable/fixed rates)
- LVR requirements
- Serviceability rules
- First home buyer schemes
- Refinancing conditions

## 🔗 Integration

This vault integrates with:
- **Layer 1**: Policy Radar Monitor (this vault)
- **Layer 2**: Insight Generator (consumes policy changes)
- **Layer 3**: FHC Growth Engine (optimizes content for conversion)

## 📝 How to Use

1. **Browse by Folder**: Navigate through organized topics
2. **Search**: Use Obsidian's search for keywords
3. **Graph View**: Visualize connections between policies
4. **Tags**: Filter by tags to find related changes
5. **Timeline**: View chronological order of changes
